# Поиск работы

## Описание:

Проект является каркасом приложения, которое будет получать данные о вакансиях с сайта HeadHunter, 
сохранять их в JSON файле, извлекать данные из файла и выполнять другие операции с вакансиями, разработан в рамках
обучения профессии Python-разработчик и закрепления пройденного материала по курсу Объектно-ориентированное 
программирование

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Viktor-Bochagov/hh_projects.git
```
2. Установите зависимости прописанные в файле pyproject.toml


## Использование:

1. Откройте проект в среде программирования PyCharm или в VsCode.
2. В вызове функций в файле `main.py` введите необходимые данные для поиска желаемых вакансий.
3. Закончив работу и получив результат закройте программу.

## Функции используемые в этой версии:

1. API для работы с hh.ru: Реализован абстрактный класс AbstractAPI и конкретный класс HeadHunterAPI, который подключается к API hh.ru и получает вакансии согласно заданным параметрам.
2. в модуле vacancies.py реализован класс Vacancy для работы с вакансиями. В данном классе определены следующие атрибуты: название, ссылка, зарплата и описание вакансии. Поддерживает методы сравнения вакансий по зарплате и валидацию данных.
3. В модуле Vacancy_handler.py реализован абстрактный класс VacancyHandler, который определяет интерфейс для работы с вакансиями, а также создан класс JSONFileHandler, наследованный от абстрактного класса, для сохранения информации о вакансиях в JSON-файл.
